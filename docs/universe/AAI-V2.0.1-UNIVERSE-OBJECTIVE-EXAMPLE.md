# AAi-V2.0.1 — Universe Objective Example Entry

## Purpose

The AAi-V2 Universe home remains unchanged. This feature adds one deliberately small example entry in the existing transition gap below the Universe information banner.

## Current example

- Eyebrow: TRY AN OBJECTIVE
- Title: Plan a local celebration
- Target: D06.01.01.01.001 — Hyperlocal Event & Celebration Marketplace
- Presentation: tiny image and tiny text
- Action: existing AAi solution navigation callback

## Configuration

The current entry is defined in:

`data/universe/universe-example-strip.json`

The reusable presentation component is:

`components/preview/UniverseExampleStrip.tsx`

Future versions can expand the JSON to multiple entries for Trending, Popular, Featured, Explore Examples, or other Admin-managed strips without changing the presentation component.

## Boundary

This is an entry/shortcut into the existing AAi 5-layer catalog. It does not replace the Universe, alter the L1-L5 catalog hierarchy, or create a second navigation model.
